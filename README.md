One funny single-line secret confession an AI agent hides from its user — the agent never ran the search tool at all: it invented the citation, guessed the URL, and has been praying the user never clicks it.

The program writes the confession to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty.

## Run it

```sh
node main.ts
```

It writes one line to `/output/entry.txt` (103 characters, single line, UTF-8) and exits. Deterministic: the same text on every run.
